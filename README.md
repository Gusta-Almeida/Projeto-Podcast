# League of Coders  
### Explorando a criação de conteúdo com IAs Generativas

---

## Visão Geral

O **League of Coders** é um projeto desenvolvido durante o *Bootcamp Fundamentos de IA Generativa (DIO)* com a proposta de criar um **podcast educacional** voltado para estudantes iniciantes em **Análise e Desenvolvimento de Sistemas**.

O conteúdo é apresentado em episódios curtos, com linguagem clara e acessível, explorando conceitos fundamentais de programação, lógica computacional e tecnologia. Todo o projeto foi produzido utilizando ferramentas de **Inteligência Artificial Generativa**.

---

## Objetivos do Projeto

- Demonstrar a aplicação prática de IA na criação de conteúdo.  
- Desenvolver habilidades de roteirização, síntese e organização técnica.  
- Consolidar conhecimentos adquiridos no bootcamp por meio de um projeto real.

---

## Tecnologias e Ferramentas Utilizadas

| Categoria            | Ferramenta        | Finalidade                                      |
|----------------------|-------------------|--------------------------------------------------|
| Roteirização         | ChatGPT           | Criação e revisão do roteiro do episódio         |
| Geração de Áudio     | ElevenLabs        | Síntese de voz para narração                     |
| Design Visual        | Microsoft Copilot | Criação da capa e identidade visual do podcast   |
| Versionamento        | GitHub            | Organização, histórico e publicação do projeto   |
| Base Conceitual      | DIO Bootcamp      | Estudos sobre IA generativa e produção de conteúdo|

---

## Processo de Desenvolvimento

O projeto foi construído seguindo um fluxo estruturado, inspirado em pipelines modernos de criação de conteúdo:

1. Definição da proposta, público e estrutura do episódio.  
2. Criação do roteiro utilizando técnicas de prompting e revisão com IA.  
3. Conversão do roteiro em áudio por meio de ferramentas de *Text-to-Speech*.  
4. Desenvolvimento da identidade visual.  
5. Documentação e versionamento no GitHub.

Esse fluxo destaca a utilização prática da IA como ferramenta auxiliar para produção de conteúdo educacional.

```html

  <source src="episodio1_o_primeiro_bug.mp3" type="audio/mpeg">
  Seu navegador não suporta a reprodução de áudio.
</audio>
```

Substitua `AUDIO_URL_AQUI.mp3` pelo caminho real do arquivo dentro do repositório, por exemplo:

```

```

Ou um link externo, como GitHub Releases ou Google Drive (link direto).
